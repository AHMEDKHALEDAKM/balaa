# Roadmap

## v0.1 local prototype — implemented here

Arabic Expo citizen flow, native capture and GPS, demonstration identity, synthetic geographic routing, duplicates, persistent local reports, test outbox, MapLibre/public tracking, district actions with before/after evidence, moderation and basic platform administration. Supabase schema/RLS/Edge foundation and web/mobile API adapter supplied.

## Remaining v0.1 integration gates

Execute the supplied Supabase adapter and database/RLS tests with Docker/PostGIS, exercise signed derivative moderation end-to-end, and run physical Android/iOS accessibility/camera/GPS tests. Replace all demo geography/contacts only with vetted sources. These are outstanding implementation/verification steps, not completed capabilities.

## v0.2 controlled pilot

Reviewed geographic data for selected locations, actual participant consent, operational moderation, retention/appeals, shared rate limiting, monitoring, tile hosting policy and device QA.

## v0.5 government pilot

Formally agreed district participation and operational routing, reviewed contact ownership and response workflow. No government endorsement may be inferred before agreement.

## v1 authorized production

Authorized identity integration, reviewed production notification transport, operational security and compliance controls.

Expansion, automated recognition/scoring, analytics, SMS/WhatsApp, payment, chat and automatic escalations remain outside this MVP.
